> Partnership marketing for the AI search era.

The AI-citation and attribution layer for affiliate-driven brands. We get your products recommended by ChatGPT, Perplexity, and Gemini — and we get paid only when it converts.

---

## What this repository is

The production source for **[affilia.com](https://affilia.com)**. Static site, deployed via Netlify. Edit `index.html`, push to `main`, Netlify auto-deploys.

## Stack

- Pure HTML / CSS (no build step required)
- Google Fonts: Fraunces (display), Inter Tight (body), JetBrains Mono (UI)
- Hosted on Netlify
- DNS managed at the registrar of record

## Local preview

```bash
# Any static server works. Examples:
python3 -m http.server 8000
# or
npx serve .
```

Open http://localhost:8000

## Deploy

`main` branch auto-deploys to production via Netlify.
